# 原生极简球：交互约定

## 内容

默认只显示 5h 剩余额度、周剩余额度以及各自重置时间。重置券数量和最近到期时间默认关闭，可从显示选项开启。套餐、Token、上下文、侧栏标记及重置预测均不展示。

账户没有返回 5h 窗口时，5h 相关数字、环和卡片行全部消失。没有有效快照时显示未知状态；不会将缺失字段补为 100% 或无限制。金额与 Token 不参与额度换算。

## 收起

- 原生版默认直径 24 个逻辑像素，显示选项中以 4 px 为步长调整到 24–80；系统 UI 字体 Segoe UI。双额度时自动放大到至少 40px，同时显示两项。网页原型仍采用较大的演示尺寸。
- 仅周额度：中央为百分比，辅以“周”标签；单环表示周剩余。
- 双额度：两行直接标明“5h”和“周”，外环对应周、内环对应 5h。
- 低额度只改变对应额度环，不改变数字含义，不持续闪烁。
- 原生版通过外围淡色环扩散表现呼吸，约 3.6 秒一个周期，不透明度从 8% 平滑变化到 72%，扩散上限受原有窗口边界约束。文字与额度环保持稳定；正常刷新不会重启动画，调整尺寸时会重新计算边界。关闭动画后不保留静止的外圈。
- 额度读取失败不暂停呼吸，也不在读取恢复后重启呼吸时钟；仅置灰旧额度并显示失败和更新时间。动画开关、系统减少动画及高对比度策略仍有效。

## 展开

- 鼠标停留 120 ms 后展开；离开球体、卡片及两者相邻边之间的窄缝后，等待 220 ms 收起。球体上方或下方、卡片外侧的空白不属于停留区域；窄缝仅用于移入卡片时防止闪烁。
- 展开、收起使用 150 ms 缓入缓出的透明度过渡；收起途中鼠标移回时从当前透明度恢复，不先隐藏再弹出。切换应用、打开原生菜单及拖动时立即隐藏；关闭动画或系统减少动态效果时省略淡入淡出。
- 单击球体固定展开，再次单击或按 Esc 收起。触屏支持点击。
- 卡片优先在球体内侧展开，空间不足时改到上方或下方，保持在当前窗口边界内。
- 每个额度窗口显示名称、剩余百分比、细进度条和本地重置时间。
- 仅在读取失败时显示“刷新失败 · 保留上次读数”；正式版还需显示上次成功更新时间，明确数据新鲜度。
- 显示选项入口收在卡片中；不在收起的球体旁排列按钮。

## 拖动与跟随

- 可绑定现有 Codex 启动器：启动包装层调用原启动器并开启悬浮球，不改 Codex 安装或原代理启动器。
- Quota Orb 快捷方式为手动开关，覆盖其他入口打开 Codex 的情况。自动启动保持幂等，不会反过来关闭已运行的球。
- 联动先启动原 Codex 快捷方式，再独立尝试启动球。球缺失或启动失败只记录本地诊断，不阻挡主程序、不弹联动错误框；新版快捷方式直接携带原入口路径，不依赖额度映射 JSON。
- 最后一个 Codex 窗口关闭后立即隐藏，最多等待 45 秒接替的更新窗口，超时退出；最小化仍视为窗口存在。首次启动等待窗口最多 30 秒，没有窗口时不会变成常驻监听。

- 超过 5 px 的移动才视为拖动，避免与点击混淆。
- 松手后按所在半区贴到左右边缘，保留竖向位置。
- 原生客户端跟随对应 Codex 窗口移动；最小化时隐藏，并依据窗口 DPI 计算尺寸与位置。
- 前台、最小化恢复和位置变化通过 WinEvent 观察，250ms 定时器仅兜底；不注入进程或拦截输入。阻塞式进程识别与配色读取不占用界面线程。
- 任务栏悬停保持原有可见性；托盘右键及原生菜单打开期间同时隐藏球与卡片，菜单关闭后按前台状态恢复。菜单、拥有者弹窗和工具窗口不能成为挂靠主窗口。
- 默认每 15 秒读取一次；系统任务栏、托盘、开始菜单取得焦点时，只要 Codex 仍是最前面的普通应用窗口，悬浮球就保留。
- 多窗口、焦点跟随、无障碍高对比度与原生贴边动画将在 Windows 客户端中验证；网页预览不作为这些能力已实现的证明。

## 预览验收

预览覆盖：无 5h / 双额度 / 低额度 / 刷新失败，重置券开关，展开与收起，点击固定，拖动贴边，以及 320–1024 px 容器中的边界约束。演示数据不发起账户或额度请求、不读取登录凭据；独立页面可能从 CDN 加载通用图标与布局组件。
